# Voice2Art

**Voice2Art** — это приложение для генерации уникальных изображений на основе голосовых или текстовых описаний. Пользователь говорит или вводит текст, система распознаёт содержание и создаёт визуальное представление с помощью нейросетей.

## Описание проекта

Проект состоит из двух частей:

- **Backend**: FastAPI-сервер, отвечающий за обработку аудио, генерацию текста и взаимодействие с моделью генерации изображений (FLUX.1 через HuggingFace API).  
- **Frontend**: Streamlit-интерфейс, где пользователь может загружать аудио, вводить текст, настраивать стиль генерации и просматривать результаты.

### Основные возможности

1. **Голос в картину**
   - Распознавание речи через Whisper
   - Перевод с русского на английский для корректной работы модели генерации
   - Генерация изображений в разных стилях (реализм, аниме, живопись, цифровое искусство, фантазия)

2. **Текст в картину**
   - Поддержка русского и английского языка
   - Настройка стиля, качества генерации, seed для воспроизводимости
   - Возможность использования негативного промпта для исключения нежелательных элементов

3. **Галерея**
   - Просмотр истории созданных изображений
   - Фильтрация по стилю и сортировка по дате
   - Скачивание изображений

4. **Настройки**
   - Управление URL API
   - Настройки генерации по умолчанию
   - Экспорт истории в JSON

## Установка и запуск

### Клонирование репозитория

```bash
git clone https://github.com/USERNAME/voice2art.git
cd voice2art
```

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск backend
```bash
uvicorn backend.main:app --reload --port 8000
```

### Запуск frontend
```bash
streamlit run frontend/app.py
```

## Конфигурация
Перед запуском необходимо добавить переменные окружения:
- HF_TOKEN — токен HuggingFace для доступа к модели FLUX.1
```bash
export HF_TOKEN="your_token_here"   # Linux / Mac
set HF_TOKEN=your_token_here        # Windows
```
